FREE LEARNING HUB — Separate project files

Files:
- index.html: page structure and Bootstrap links
- style.css: visual design and responsive card styling
- app.js: search, filters, favorites, watched status, recent history and embedded player
- videos.js: all 49 YouTube links and editable display titles

Run:
1. Download all four files into the SAME folder.
2. Open index.html in Chrome or another modern browser.
3. Keep internet access on for Bootstrap CDN, thumbnails and YouTube playback.

Notes:
- Favorites, watch history, and watched status are saved in the browser using localStorage on that device.
- Titles are placeholders based on the order of the links because actual video titles were not supplied in the message.
- Embedded playback may be disabled for some YouTube videos; use the Open on YouTube button in that case.
- Bootstrap is loaded from a CDN, so internet access is required.
